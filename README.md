## 🚀 Featured Projects

### 🚦 Stop-and-Go Pedestrian Crossing Signal Controller

A Verilog-based pedestrian crossing signal controller designed using **Finite State Machine (FSM)** concepts.

The project focuses on controlling vehicle and pedestrian signals while implementing safe state transitions.

**Tech:** `Verilog` `FSM` `Digital Design`

---

### 🔧 Adaptive Closed-Loop Infusion Pump with Occlusion Prediction

A hardware-oriented project exploring **real-time motor current analysis, signal processing, and occlusion prediction** for an adaptive closed-loop infusion pump.

The project combines signal analysis with intelligent control concepts.

**Tech:** `C++` `Signal Processing` `Hardware Systems`

---

### ⚙️ Comparative Analysis of Hardwired and Microprogrammed Control Units

A comparative analysis of **hardwired and microprogrammed control units**, evaluating parameters such as execution time, CPI, IPC, and CPU efficiency.

**Tech:** `C` `Computer Architecture` `Digital Systems`

---

### ☁️ Dynamic Cost-Aware HEFT

A task scheduling approach extending the traditional **Heterogeneous Earliest Finish Time (HEFT)** algorithm with dynamic cost awareness for cloud-based heterogeneous computing environments.

**Tech:** `Python` `Cloud Computing` `Task Scheduling`
